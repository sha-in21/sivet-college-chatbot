# College Enquiry Chatbot 🤖

A web-based chatbot application developed to help students get instant answers for common college-related queries such as admissions, courses, fees, and campus information.

## 🚀 Features

- Student enquiry assistance
- Instant chatbot responses
- Admission information
- Course details
- Fees information
- Campus related queries
- User-friendly interface
- Firebase authentication
